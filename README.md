# diagnet

Портативный набор диагностики качества сети для Windows: плановые проверки
по расписанию и веб-дашборд для просмотра журналов и настройки — всё из
браузера, без установки и прав администратора.

## Что умеет

- **Основная проверка** (интервал настраивается): ping роутера и 8.8.8.8,
  DNS по UDP и TCP напрямую к резолверам, время HTTPS-соединения,
  трассировка. Отлично ловит эпизоды вида «ICMP и TCP живы, а UDP/53
  провайдер режет».
- **Проверка по узлам** (стиль WinMTR): параллельный ping каждого хопа
  маршрута (по умолчанию 1000 пакетов каждые 30 минут) — показывает,
  на каком именно узле маршрута появляются потери.
- **Веб-дашборд** (http://127.0.0.1:8471): два журнала с фильтрами и
  подсветкой, статистика, кнопки ручного запуска, все настройки,
  установка/удаление задач Планировщика прямо из браузера.

## Быстрый старт

1. Скопируйте папку на любой ПК с Windows 10 (1803+) / 11.
2. Запустите `ЗАПУСК.bat`. Откроется дашборд; при первом запуске рядом
   создастся ярлык с иконкой.
3. Python не обязателен — при необходимости скачается автоматически
   (~12 МБ, один раз).
4. В дашборде: «Настройки» → «Установить задачу».

## Структура

- `ЗАПУСК.bat` — точка входа
- `icon.ico` — иконка (ярлык, favicon)
- `service/` — служебные файлы: `viewer.py` (сервер дашборда, stdlib),
  `diag.bat` и `hopcheck.ps1` (проверки), `config.bat` (параметры),
  задачи Планировщика

Только встроенные средства Windows: cmd, PowerShell, curl, tar.
Дашборд слушает 127.0.0.1:8471, наружу не выходит.

Подробности — в `README.txt` и `AGENTS.md`.
