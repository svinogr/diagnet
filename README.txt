СЕТЕВАЯ ДИАГНОСТИКА
==================

Папка проверки качества сети: два журнала (основной и по узлам
маршрута), веб-дашборд, всё управление из браузера.

КАК ПОЛЬЗОВАТЬСЯ
----------------
1. Запустите файл ЗАПУСК.bat (двойной клик).
   Откроется дашборд в браузере: http://127.0.0.1:8471/
   При первом запуске рядом появится ярлык
   «Сетевая диагностика» с иконкой - можно пользоваться им.
   Python не обязателен: если он не установлен, при первом
   запуске он скачается сам (~12 МБ, нужен интернет один раз).

2. В дашборде, вкладка «Настройки»:
   - «Расписание автоматической проверки» - интервал и кнопка
     «Установить / обновить задачу» (один запрос UAC - «Да»).
   - «Проверка по узлам» - цель, число пакетов, интервал,
     кнопка «Установить задачу».
   - «Основная проверка» - цели, DNS-серверы, включение
     отдельных проверок.

3. Журналы - на вкладке «Журнал» (переключатель
   «Основной журнал» / «Журнал по узлам»).
   Ручной запуск любой проверки - кнопки «Запустить сейчас».

ЧТО ГДЕ ЛЕЖИТ
--------------
ЗАПУСК.bat      - единая точка входа, всё начинается с него
icon.ico        - иконка набора и дашборда
service\        - служебные файлы (можно не трогать):
                  viewer.py (сервер дашборда), diag.bat и
                  hopcheck.ps1 (сами проверки), задачи,
                  конфигурация config.bat
README.txt      - этот файл
AGENTS.md       - описание проекта для разработчиков/ИИ

УДАЛЕНИЕ ЗАДАЧ
--------------
В дашборде, вкладка «Настройки»: кнопки «Удалить задачу».
Или в командной строке:
  schtasks /Delete /TN "NetDiagHourly" /F
  schtasks /Delete /TN "NetDiagHopCheck" /F

ТРЕБОВАНИЯ
----------
Windows 10 (1803+) или Windows 11. Интернет нужен один раз,
если Python не установлен (авто-загрузка ~12 МБ).
